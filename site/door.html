Choose Your Door — one decision, fully shown

One room. Three-to-five doors. One character — health, weapon, knowledge, torches, objective — and four personalities: coward, greedy, brave, steady. The point of the demo is that personalities are policy, not code paths: the same scorer, the same wire request, different weights — decision policy + state → decision. The ladder scores every door, the confidence is a softmax over the scores, and the exact request the engine saw is printed on the page. Balance the doors with no objective and the scores dead-heat: the engine abstains, nobody moves, and the UI says why. Run the series and watch the same room sequence play out differently under each policy.

What decides what

  • Personalities are policy, not code paths. The coward does not run different code from the greedy — the same scorer reads the same door traits, only the weights differ (danger ×3 for the coward, reward ×3 for the greedy, the brave SEEK danger). The series panel replays one room sequence under all four policies so the divergence is visible at volume.
  • The state bites through the same weights. A hurt, unarmed character fears the same danger number more — the weight is scaled by health and weapon, never swapped out. Knowledge shrinks mystery's pull; torches soften effort.
  • Confidence is a softmax over the ladder scores and rides on the wire as the request's context; the personality also ships its risk field (coward low, brave high). The exact request — state text, candidate list, policy — is printed under the verdict.
  • Abstention is reachable and first-class. Balance the doors with no objective: identical traits, a dead heat, no argmax — the engine declines, the verdict panel says NOBODY MOVES, and the why explains the canonical refusal case. 13 core tests run in CI.

Honest edges

  • There is no consequence engine: nothing chases you through the door. This is the "can it decide?" rung of the suite — the decision, the confidence, the scores, and the trace are the whole game, on purpose.
  • The ladder is a weighted trait sum, not a simulator: door traits are drawn (reward leans on danger), not simulated outcomes. Two doors with the same numbers are the same door to it — which is exactly how the abstention demo works.
  • The series runs LADDER-ONLY — no engine asks — so the bars are pure policy. Every 4th room is the balanced dead-heat setup, and without a bridge the ladder tie-breaks by door order rather than abstaining (it says so out loud).
  • The engine lane is one ask per room: this room has one decision. The decide button after a decision deals a fresh room instead — there is no take-backs.
  • The scoreboard is session-only, one row per decision or abstain: close the tab and it is gone. Nothing leaves this page.
